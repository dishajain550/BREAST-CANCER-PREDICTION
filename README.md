# BREAST-CANCER-PREDICTION

# 🎗️ Breast Cancer Detection using Machine Learning

This project presents a complete **Machine Learning-based classification system for Breast Cancer prediction** using medical diagnostic data. The goal is to assist in early detection by applying powerful ML models with proper data analysis.

---

## 🎯 Project Goals

* Perform deep **Exploratory Data Analysis (EDA)**
* Understand key medical features influencing cancer detection
* Apply multiple classification algorithms
* Compare model performance using accuracy and evaluation metrics

---

## 🔍 Key Implementation Steps

* Data Cleaning & Feature Selection
* Correlation Analysis & Heatmaps
* Feature Scaling & Data Normalization
* Model Training & Testing
* Performance Evaluation using Confusion Matrix & Accuracy Score

---

## 🤖 Machine Learning Models Used

* Logistic Regression
* Decision Tree Classifier
* Random Forest Classifier
* K-Nearest Neighbors (KNN)

---

## 📊 Dataset Information

* Total Records: **569**
* Total Features: **30+**
* Target Class: **Diagnosis**

  * Benign (0)
  * Malignant (1)

---

## 📈 Results & Interpretation

* The models achieved **high classification accuracy**
* Random Forest and Logistic Regression showed the **best performance**
* The system can effectively assist in **early-stage cancer prediction**

---

## 🛠️ Technologies Used

* Python
* Pandas, NumPy
* Matplotlib, Seaborn
* Scikit-learn
